# MGT Filtre - Depo Sipariş Formu

Web tabanlı sipariş formu uygulaması.

## 🌐 Canlı Demo

**Web Form**: [https://depoistek.vercel.app](https://depoistek.vercel.app)

**API**: [https://api.depoistek.com.tr](https://api.depoistek.com.tr)

## 🚀 Özellikler

- ✅ Gerçek zamanlı stok kontrolü
- ✅ Otomatik ürün arama
- ✅ Çoklu ürün siparişi
- ✅ Responsive tasarım
- ✅ Kalıcı API bağlantısı

## 🛠️ Teknolojiler

- HTML5
- CSS3
- Vanilla JavaScript
- Cloudflare Tunnel
- Vercel Hosting

## 📦 API Endpoints

- `GET /stok` - Stok listesi
- `POST /siparis` - Yeni sipariş
- `GET /siparisler` - Sipariş listesi
